## 项目概述
构建一个部署在 GitHub Pages 的"部落冲突阵型展示站"，包含展示端和管理端。

## 技术栈
- **Frontend**: React + Vite + Tailwind CSS
- **Data**: 本地 `public/data.json`
- **Local Server**: Node.js + Express + multer + sharp

## 核心功能

### 1. 展示端 (User View)
- 瀑布流展示阵型图片 (CSS columns)
- 顶部搜索框 + 标签筛选
- 点击卡片打开侧边栏 Drawer，显示详情和"复制链接"按钮

### 2. 管理端 (Admin View)
- 路由: `/admin`
- 表单功能：上传图片、输入标题/链接、选择或新建标签
- 提交逻辑：POST 到 `http://localhost:3001/api/add-layout`

### 3. 后端 server.js
- Express + multer 处理文件上传
- sharp 处理图片：调整宽度1000px，转 webp，质量80%
- `/api/add-layout` 接口：保存图片到 `public/images/`，追加记录到 `data.json`

### 4. Package.json Scripts
```json
"dev": "concurrently \"vite\" \"node server.js\""
```

## 部署流程
1. 本地运行 `npm run dev` 启动 Vite + server.js
2. 访问 `http://localhost:5173/admin` 添加阵型
3. 图片自动保存到 `public/images/`，数据追加到 `public/data.json`
4. 手动 `git add . && git commit && git push` 部署到 GitHub Pages

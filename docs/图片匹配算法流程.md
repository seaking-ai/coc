# 图片匹配算法流程

## 概述

基于ORB关键点检测的图片相似度匹配算法，用于COC阵型图片搜索。

**算法优势**：
- 对裁剪鲁棒：检测关键点而非比较整体图，部分截图只要有足够关键点就能匹配
- 对颜色/等级免疫：ORB描述子关注梯度方向，不同等级城墙纹理不同但拐角结构不变
- 计算量可控：浏览器端ORB提取约50-100ms，匹配几百张图约200ms
- 无需大模型：不需要下载深度学习模型，OpenCV.js轻量加载

## 核心组件

### 1. 特征提取算法

**算法选择**: ORB (Oriented FAST and Rotated BRIEF)
- 关键点检测：FAST算法检测角点（城墙拐角、建筑边缘等）
- 描述子：BRIEF二进制描述子，32字节/关键点
- 最大关键点数：500个
- 图像尺寸：最大512x512（保持性能）

**ORB参数配置**
- nfeatures: 500 (最大特征点数)
- scaleFactor: 1.2 (金字塔缩放因子)
- nlevels: 8 (金字塔层数)
- edgeThreshold: 31 (边缘阈值)
- patchSize: 31 (特征点周围区域大小)

### 2. 特征提取流程

**图片预处理**
1. 加载图片到HTMLImageElement
2. 调整大小到最大512x512（保持性能）
3. 转换为灰度图

**关键点检测**
1. 使用ORB检测关键点位置
2. 计算每个关键点的方向（旋转不变性）
3. 生成BRIEF二进制描述子

**输出格式**
```json
{
  "keypoints": [
    {"x": 100, "y": 200, "size": 31, "angle": 45.5, "response": 0.85, "octave": 0}
  ],
  "descriptors": [[...32 bytes...]],
  "width": 512,
  "height": 512
}
```

### 3. 相似度计算

**匹配流程**
1. **BFMatcher**: 暴力匹配查询图与目标图的描述子
2. **KNN匹配**: k=2，为每个查询点找到2个最近邻
3. **Lowe's比率测试**: 筛选优质匹配（最佳匹配距离 < 0.75 × 次佳匹配距离）
4. **RANSAC筛选**: 使用单应性矩阵估计剔除几何不一致的匹配

**相似度公式**
```
similarity = min(100, inliers × 2 + inlierRatio × 30 + coverageRatio × 50)
```

其中：
- inliers: RANSAC内点数量
- inlierRatio: 内点比例（内点数/总匹配数）
- coverageRatio: 覆盖率（内点数/最小关键点数）

**部分截图支持**
- 用户上传部分截图时，只要包含足够多的关键点（城墙结构）
- RANSAC会找到几何一致的匹配子集
- 内点数量决定相似度高低

### 4. 索引结构

**文件格式**: JSON

**字段定义**
- version: 索引版本号
- algorithm: 算法标识（"orb-keypoints"）
- maxKeypoints: 最大关键点数（500）
- generatedAt: 生成时间戳
- layouts: 阵型特征数组

**单条记录结构**
```json
{
  "id": "阵型唯一标识",
  "image": "/images/layout_xxx.webp",
  "keypoints": [{"x": 100, "y": 200, ...}],
  "descriptors": [[...32 bytes...]],
  "width": 512,
  "height": 512
}
```

### 5. 搜索流程

**查询阶段**
1. 初始化OpenCV.js（首次）
2. 提取查询图片的ORB关键点和描述子
3. 加载本地关键点索引文件

**匹配阶段**
1. 遍历索引中所有阵型
2. 使用BFMatcher + KNN匹配描述子
3. Lowe's比率测试筛选优质匹配
4. RANSAC估计单应性矩阵，筛选内点
5. 基于内点数量计算相似度
6. 按相似度降序排序
7. 取Top-N结果

**结果组装**
1. 从data.json加载阵型元数据
2. 合并相似度分数与阵型信息
3. 返回完整结果列表（包含匹配信息）

### 6. 索引生成流程

**浏览器端生成（Admin页面）**
1. 加载OpenCV.js
2. 遍历所有阵型图片
3. 提取ORB关键点和描述子
4. 生成keypoint-index.json
5. 下载或复制到剪贴板

**服务器端生成（Python脚本）**
```bash
python scripts/generate-keypoint-index.py
```
- 使用Python OpenCV离线处理
- 生成相同的索引格式
- 适合批量处理大量图片

**进度管理**
- 实时显示处理进度
- 记录成功/失败数量
- 输出错误日志

### 7. 性能指标

**特征提取速度**: ~100ms/张（512x512图像）
**匹配速度**: ~200ms/千张（含RANSAC筛选）
**索引文件大小**: ~120KB/阵型（500关键点×(32+6)×4字节）
**OpenCV加载时间**: ~1秒（首次）

### 8. 部署架构

**静态站点 (GitHub Pages)**
- 预计算关键点索引（keypoint-index.json）
- 客户端关键点匹配
- 无需后端服务

**本地开发**
- Admin页面生成索引
- 浏览器端OpenCV处理
- 一键导出索引文件

## 文件结构

```
src/
├── utils/
│   └── keypoint-matcher.js          # 核心匹配算法
├── components/
│   ├── search/
│   │   └── ImageSearch.jsx          # 图片搜索组件
│   └── admin/
│       └── KeypointIndexGenerator.jsx  # 索引生成组件
└── pages/
    └── Admin.jsx                    # 管理页面

scripts/
└── generate-keypoint-index.py       # Python索引生成脚本

public/
└── index/
    └── keypoint-index.json          # 关键点索引文件
```

## 使用方法

### 1. 生成索引（Python推荐）

```bash
python scripts/generate-keypoint-index.py
```

### 2. 或浏览器端生成

1. 访问Admin页面
2. 点击"生成索引"按钮
3. 下载keypoint-index.json
4. 放入public/index/目录

### 3. 测试搜索

1. 启动开发服务器
2. 上传阵型截图
3. 查看匹配结果
